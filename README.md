# Titanic Dataset Analysis

This repository contains an analysis of the Titanic dataset, focusing on data cleaning and exploratory data analysis (EDA) to explore key insights into the survival rates of passengers.

## Project Overview

The project includes:
- **Data Cleaning**: Handling missing values, removing unnecessary columns, and preparing the dataset for analysis.
- **Exploratory Data Analysis (EDA)**: Visualizations and statistics to uncover patterns related to passenger demographics, ticket class, and survival rates.

## Dataset

The dataset used in this project is the **Titanic dataset**, which includes information about passengers on the Titanic, such as age, gender, ticket class, and whether they survived the disaster. You can download the dataset from [Kaggle](https://www.kaggle.com/c/titanic).

### Key Columns:
- `Survived`: Survival (0 = No, 1 = Yes)
- `Pclass`: Passenger Class (1 = 1st, 2 = 2nd, 3 = 3rd)
- `Sex`: Gender
- `Age`: Age of Passenger
- `SibSp`: Number of siblings/spouses aboard the Titanic
- `Parch`: Number of parents/children aboard the Titanic
- `Fare`: Passenger Fare
- `Embarked`: Port of Embarkation (C = Cherbourg, Q = Queenstown, S = Southampton)
